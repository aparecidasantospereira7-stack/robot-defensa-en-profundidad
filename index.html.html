Defensa en profundidad

Varias capas de protección, una dentro de otra. Si una falla, la siguiente sigue cuidando el equipo.

Toca “Lanzar ataque” y mira cómo cada capa cubre una debilidad distinta.

Capas, de afuera hacia adentro

    Toca una capa para apagarla y lanza otro ataque: aunque una falle, las demás siguen protegiendo. Si apagas todas, el robot queda sin defensa.
